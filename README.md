## About this site

Built with Next.js 16 (Pages Router) and React 18 in TypeScript, styled with CSS Modules, charts with Recharts, exported as a static site and deployed to Firebase Hosting.

To run it locally:

```bash
npm install
npm run dev
```

To build the static export:

```bash
npm run build
```
